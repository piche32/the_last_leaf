2. **마감 시간:** 당일 **17시 59분 59초**까지
3. **판정 기준:** `18시 00분 00초`가 되는 순간부터 가차 없이 **실패(지각)**로 간주합니다.
   - ⚠️ 로컬 PC의 Commit 시간이 아닌, **GitHub 서버에 기록된 PR(Pull Request) 생성 시간**을 기준으로 판정합니다.
4. **패널티 (벌금):** 1회 실패 시 **50,000원** 즉시 납부
   - 발생 당일 `23:59`까지 모임통장으로 입금해야 합니다.
   - 기한 내 미입금 시 **매일 5,000원의 연체료**가 추가됩니다.
5. **벌금 사용처:** 모인 벌금은 전액 스터디 종료 후 **서울 여행 경비(숙박, 식비 등)**로 사용합니다. (중도 하차 시 기납부 벌금 환불 절대 불가)

## 📂 폴더 구조 및 제출 방법

당일 제출 현황을 한눈에 확인하기 위해 **날짜별 폴더(`YYYY-MM-DD`)**를 생성하고, 그 안에 **본인 이름의 마크다운 파일**을 업로드합니다.

### 1. 폴더 및 파일명 규칙
* **폴더 경로:** `YYYY-MM-DD/본인이름_라이브강의제목.md`

```text
📦 study-repo
 ┣ 📂 2026-10-26
 ┃ ┣ 📜 김철수_Java_컬렉션프레임워크.md
 ┃ ┣ 📜 이영희_Java_컬렉션프레임워크.md
 ┃ ┗ 📜 박민수_Java_컬렉션프레임워크.md
 ┣ 📂 2026-10-27
 ┃ ┣ 📜 김철수_알고리즘_DFS와BFS.md
 ┃ ┗ 📜 이영희_알고리즘_DFS와BFS.md
 ┗ 📜 README.md
```

### 2. 제출 프로세스 (PR 방식)
1. 작업 전 `git pull`을 받아 오늘 날짜(`YYYY-MM-DD`) 폴더가 이미 있다면 해당 폴더 안에, 없다면 새로 폴더를 만들어 본인 이름의 `.md` 파일을 작성합니다.
2. **본인 이름의 브랜치**에 Push 한 뒤, `main` 브랜치로 향하는 **Pull Request(PR)**를 생성합니다.
   - **PR 제목 양식:** `[YYMMDD] 이름 - 강의주제` (예: `[261026] 김철수 - Java 컬렉션 프레임워크`)
3. PR 생성 시각이 `17:59:59` 이내인지 확인합니다.
